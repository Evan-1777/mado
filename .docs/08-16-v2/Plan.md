# Plan：修复目录栏折叠/展开与目录识别为空

**状态**：DONE  
**日期**：2026-08-16  
**版本**：v1.0  
**回归测试结论**：esbuild 零产物语法检查、`npm run build`、parseToc 复现脚本（用户样例 + 真实 fence 用例）全部通过；`go vet ./...` 与 `go test ./...`（4 包）无回归。

---

## 1. 背景与目标

用户报告两个问题：

1. **目录栏没有按要求支持向左折叠与展开**：Editor/Preview 聚焦模式下的目录侧栏固定占 248px，无收起按钮、无整栏折叠能力。08-15-v2 计划只实现了"节点级折叠/全部展开"，未实现侧栏整体折叠。用户确认折叠形态为：**窄条 + 悬停弹层**（折叠后留 ~24px 窄条，点击展开恢复；悬停临时浮出目录，移开收回）。
2. **目录识别为空**：大量含 `#` 标题的文档（如网页动画方案文档）显示"当前文档没有标题"。根因已定位：`frontend/src/main.ts` 中 4 处正则/字符串双反斜杠字面量错误（`\\s`、`\\n`、`\\\\/`），esbuild 原样输出后运行时正则变成"匹配字面反斜杠+字母"，任何标题都匹配不上；`split('\\n')` 也不换行（整篇文档成一行）。该缺陷已随 08-15-v2 提交进 git（HEAD 与工作树一致）。

目标：

- 目录栏可向左折叠为窄条、可展开恢复，折叠态悬停浮出目录弹层
- 含多级 `#` 标题的文档目录正确显示，层级、折叠、跳转均正常
- 不破坏既有行为：Split 模式无侧栏；Editor/Preview 模式才显示；节点级折叠/全部展开保留

## 2. 阶段划分

| **验收标准** | 折叠后侧栏收窄为 ~24px 窄条，内容区占满；点击窄条或按钮恢复完整侧栏；折叠态悬停窄条浮出目录弹层、移开收回；Editor/Preview 模式切换后折叠状态保留；Split 模式无侧栏 |

## 3. 架构决策

| 决策项 | 选择 | 理由 | 替代方案（为何不选） |
|--------|------|------|----------------------|
| 折叠状态 | 前端模块级布尔变量（不持久化） | 单窗口会话内一致即可；无后端状态需求 | localStorage 持久化（会话级记忆收益低，增加复杂度） |
| 折叠形态 | 窄条（~24px）+ 悬停浮层 | 用户选定；保留一键恢复入口，悬停可临时查阅目录 | 完全隐藏（恢复入口隐蔽）；仅点击展开（查阅目录需先展开） |
| 浮层实现 | 绝对定位浮层，`mouseenter/leave` 控制，延迟收起（transitionend 兼容） | 无依赖、行为可预测 | 弹出锚定到 iframe/多列（无必要） |
| 数据源 | 沿用前端 parseToc（修复后） | 编辑器跳转需原文行号，前端解析最合适 | 后端渲染回调目录（新增绑定，收益低） |

## 4. 风险清单

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 悬停浮层频繁弹出干扰输入 | 🟡 中 | 仅在折叠态显示浮层；`mouseleave` 后延迟收起（~200ms）防抖动 |
| 浮层内点击跳转后弹层遮挡预览 | 🟢 低 | 点击后立即收起浮层 |
| 折叠窄条点击热区过小 | 🟢 低 | 窄条全宽可点击，加宽 hover 背景反馈 |
| 正则修复后标题含 `#` 内联样式/特殊字符解析差异 | 🟢 低 | 复现脚本覆盖用户样例（含 HTML 块、表格） |
