## 1. 背景与目标

当前状态：

- 预览不支持数学公式（v1 曾列为非目标，本期按需求解除）
- 用户偏好仅主题一项，散落于标题栏快捷按钮，无统一设置入口
- 偏好持久化位于用户配置目录（`%APPDATA%/Mado/settings.json`），需求变更为 **exe 同目录 settings.json**（便携化）

本期目标：

1. 预览支持 `$...$` 行内与 `$$...$$` 块级公式渲染，视觉标准对齐 KaTeX
2. 新增设置页：整合主题切换、编辑器自动换行、公式渲染开关三类配置项
3. 全部用户偏好实时生效并持久化至 exe 目录下 settings.json（含既有主题与最近文件记录整体迁移，不丢失旧数据）

## 3. 架构决策

| 决策项 | 选择 | 理由 | 替代方案（为何不选） |
|--------|------|------|----------------------|
| 公式渲染管线 | Go 解析定界符输出占位元素，前端（父上下文）KaTeX 渲染后写回帧 DOM | 预览帧 sandbox 无 allow-scripts（既有安全模型），父上下文经 allow-same-origin 可跨帧操作 DOM；KaTeX 体积/性能/成熟度均衡，渲染发生在 WebView 内零额外二进制开销 | 服务端渲染（纯 Go JS 引擎 quickjs 依赖链重、二进制显著增大）；放开帧内脚本（破坏既有 script 剥离与 sandbox 安全决策） |
| 数学语法解析 | `$` 行内 + `$$` 块级，自研轻量 goldmark 扩展 | 语法面小、输出占位格式完全可控；渲染包已有自定义 ID 生成器先例，风格一致 | 第三方 mathjax 扩展（块级渲染依赖外部 SVG 服务，离线不可用、行为不可控） |
| KaTeX 静态资源 | 随前端构建产物分发（样式+字体），预览帧骨架内以样式表链接加载 | srcdoc 帧继承父文档基础 URL，相对路径经内嵌资产服务解析；字体与样式就近同目录加载 | Go 内嵌公式样式再注入（字体 URL 仍需相对解析，绕路无收益） |
| 存储位置 | 共享 settings.json（偏好 + 最近文件记录）整体迁移至 exe 目录；启动时旧位置一次性复制迁移 | 用户明确要求便携化；保持「单文件共享存储、顶层字段互不干扰」既有架构不变 | 仅偏好迁移（两个同名 settings.json 并存易混淆）；welcome 文档保留在用户配置目录（文档非偏好，避免 exe 目录堆积） |
| 存储格式 | JSON 值类型放宽（字符串→任意值），读写双方维持键级共存 | 布尔开关与字符串键共存必需；延续既有松耦合约定 | 偏好与状态分文件（违背既有共享单文件设计） |
| 设置页形态 | 标题栏齿轮按钮唤出的模态面板，含主题/自动换行/公式渲染三行控件；保留既有主题快捷按钮 | 单视图应用无路由概念；原生 dialog 提供 Esc/焦点囚禁（同关闭确认模态先例）；快捷按钮与面板双入口同步 | 独立窗口（重）；工具栏菜单（与极简 UI 不符） |
| 新偏好默认值 | 主题 dark（沿用）、自动换行开、公式渲染开 | 公式渲染为本期核心诉求，默认关则功能不可见；Markdown 编辑器自动换行为惯例 | 默认关（新功能不可见，违背诉求） |

## 4. 风险清单

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| srcdoc 预览帧内相对路径样式/字体能否经资产服务加载，Windows 端验收滞后 | 🟡 中 | 本地构建核对产物路径与链接一致性；预留退路：改为样式文本注入帧内（扩展 GetCSS 组装公式样式） |
| `$` 货币语义误判（如 `$5 and $10`）与 `\$` 转义边界 | 🟡 中 | 行内公式内容首/尾非空格启发式 + 单测锁定行为；不支持跨行行内公式记为已知限制 |
| 存储迁移期间两包路径不同步造成读写分裂 | 🟢 低 | Phase 1 内闭环完成，阶段验收统一跑两包测试 |
| exe 所在目录不可写（如安装到受保护位置） | 🟢 低 | 个人便携部署场景（SCOPE 约定），已知限制记入文档 |
| KaTeX 静态资产约 1.3MB 嵌入 exe | 🟢 低 | 功能优先级高于体积增量，接受并记入决策 |
| 新增 Go 绑定与前端绑定副本不同步导致本地验证链断裂 | 🟢 低 | 既有约束已记录（Project.md §6），Task 内显式含同步步骤并 grep 验证 |
