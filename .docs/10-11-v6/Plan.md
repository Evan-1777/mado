## 1. 背景与目标

针对 10-11-v5 审阅报告中发现的 5 项技术细节进行批判性吸收，严格遵守工程纪律（溯源根因、规范克制、最短有效差分）：
- **问题 1（样式泄漏与外壳污染·高）**：`pdfExporter.ts` 将全局预览样式表注入主文档，导致导出期间外壳 `body` 被强加 `36px` 顶内边距、`max-width: 52rem` 并临时翻转 `:root` 主题令牌。将捕获源结构归位至离屏隔离 `iframe`，彻底实现物理隔离，消除一切样式与布局污染。
- **问题 2（页边距数值与文案不符·中）**：`pdfExporter.ts` 的边距像素（左右 50/32/80px）与界面标注的「标准 (20mm) / 紧凑 (10mm) / 宽松 (30mm)」存在 35%~40% 偏差。按 96 DPI（3.78 px/mm）严格重算像素值（76px / 38px / 114px），使实现与界面承诺完全对齐。
- **问题 3（深色底色接缝·低）**：深色画布/边距填充硬编码 `#202020`，与 `tokens-dark.css` 的 `--bg: #1f1f1f` 存在色差接缝。统一收敛为 `#1f1f1f`，消除缝隙。
- **问题 4（静默截断丢内容·低）**：分页循环由内容高度与页高确定性收敛，100 页硬截断属于过度防御且会导致长文档静默丢弃后半部分。果断移除该无用防御。
- **问题 5（.gitignore 范围过大·低）**：`.gitignore` 整体忽略 `.codebuddy/` 与已跟踪的 agents/skills 产生冲突。将忽略规则精准收窄到 `.codebuddy/*.local.json`。

## 3. 架构决策

| 决策项 | 选择 | 理由 | 替代方案（为何不选） |
|--------|------|------|----------------------|
| 样式隔离方式 | 离屏隔离 `iframe` 容器 | 溯源根因与结构归位；iframe 是浏览器一等公民的物理样式隔离边界，彻底阻断任何 CSS 泄露 | 正则改写/前缀注入全部 CSS 规则（脆弱、复杂且无法彻底避免标签全局匹配） |
| 页边距对齐 | 更新像素值为 76/38/114px | 96 DPI 物理换算精确对应 20mm/10mm/30mm，保留直观的物理毫米文案承诺 | 修改文案为非整数像素折算 mm（破坏界面美观与标准打印感知） |
| 100 页截断 | 彻底移除过度防御 | 分页算法在数学上严格单调递增保证终止；静默截断违反数据完整性原则 | 弹出警告框提示截断（增加无效交互代码） |
| .codebuddy 忽略 | `.codebuddy/*.local.json` | 仅忽略本地工作区生成的动态配置，恢复受控 agents 与 skills 的版本跟踪 | 保持全目录忽略（导致后续新增工具被静默丢弃） |
