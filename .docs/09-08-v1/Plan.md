**状态**：DONE

**完成日期**：2026-09-08
**版本**：v1.0
**回归测试结论**：通过 `go vet ./...`、`go test -race ./...`、前端 esbuild 零产物语法检查、`npm test`、`npm run build`、字体 woff2 动态对照与重复构建、`node tests/modeScroll.check.mjs`、`node tests/startup.check.mjs`。

## 1. 背景与目标

Mado 功能面已稳定（v1.7），本次对三条线做集中治理，遵循 SCOPE「轻量低占用」与最短有效差分原则：

1. **启动速度**：消除启动路径上的重复渲染与瞬时脏标记，收敛为单次渲染。
2. **运行性能**：修复渲染调度节流失效（实际为纯防抖）；预览写入增加解耦变更检测，消除无谓的整帧样式重算与 DOM 重建。
3. **漏洞检索**：对渲染输出、文件持久化、并发绑定三条信任边界做安全审查，修复确认问题，其余记录为已接受边界。

**非目标**（本次明确不做）：增量 DOM 渲染架构、KaTeX 懒加载/代码分割、预览帧 CSP、goldmark 引擎复用、mathCache 淘汰策略调整、单实例限制——理由见 §4 拒绝项。

## 2. 现状发现（Explore 结论）

### 启动

- **F1 启动/打开多次渲染**：主题应用路径自带一次渲染（启动时作用于空文档）；加载文档的显式渲染之外，编辑器文档变更监听对程序性文档替换同样生效，会在约 100ms 后对同一内容再排程一次渲染。同模式使每次文件打开与新建都伴随一次冗余渲染（带启动文件时启动全程共 3 次 Render 调用）。
- **F2 启动瞬时脏标记**：加载文档时监听器先置脏、流程再清脏，产生一对多余 IPC；极端时序下（置脏 IPC 已达、清脏未达时 Alt+F4）会对刚打开的干净文档误弹未保存确认。

### 运行

- **F3 节流失效（缺陷）**：调度实现中防抖下限（100ms）恒大于节流间隔（80ms），且每次击键都清除并重置定时器——实际是纯 100ms 防抖，连续输入/输入法组字期间预览完全不更新，直到停顿。与 2026-08-14「100ms 防抖 + 80ms 节流」的既定设计及 2026-09-02「使 80ms 节流生效」的修复意图相悖（该次修复只更新了时间戳，未触及定时器重置与常量覆盖关系）。
- **F4 预览无条件重写**：每次渲染都重写帧内样式文本与正文 innerHTML，即使与上次完全相同——相同的样式文本写入同样会使整帧样式失效并触发重算，叠加全量 DOM 重建与 KaTeX 遍历，是长文档编辑期的主要无谓开销。

### 漏洞

- **F5 保存非原子（数据损坏风险）**：文件保存直接截断覆写目标文件，写入中途进程崩溃或失败会破坏用户文档已有内容。治理目标为同目录临时文件、继承原文件权限、`f.Sync()` 刷盘后原子替换（Crash-resilient Best-effort Save）；任一步骤失败清理临时文件，确保旧文件毫发无损；不宣称 Windows 或底层文件系统的跨平台绝对断电原子性。
- **F6 绑定层数据竞争**：Wails 每个绑定调用运行在独立 goroutine。设置结构体在偏好写入与渲染/取样式/取设置读取之间无同步；dirty 与 quitting 标志在绑定写入与 `main.go` 关闭钩子（`OnBeforeClose` 同步回调）直接读取之间无同步；此外最近文件记录与偏好保存对同一共享 JSON 文件并发读改写，后写者覆盖前者，存在丢更新。治理目标：App 单一 `sync.RWMutex` 守护状态，提供加锁只读方法供 `main.go` 安全读取，单进程内串行化共享 JSON 写路径；跨进程竞争属于已接受的多实例限制。
- **F7 meta refresh 未剥离（预览杀死 + 隐私）**：sandbox 允许 iframe 自导航，且 meta refresh 不产生可被父侧拦截的 click 事件；文档中的 `<meta http-equiv="refresh">` 原样进入预览帧后，可静默把帧导航到任意外部 URL（预览失效 + 回连追踪）。净化须识别属性双引号/单引号边界（防止属性值含 `>` 截断标签）并精准剥离 `refresh` token（保留 `refresh-policy` 等合规值）。
- **F8 打开确认晚于副作用**：打开与拖放流程在「未保存确认」之前就触发窗口标题变更与最近文件记录；用户在确认弹窗中取消后，原生窗口标题已指向新文件（与编辑内容不一致），最近文件亦误记。
- **F9 拖放读文件失败静默**：拖放回调无错误处理，读取拒绝成为未处理的 Promise 拒绝，用户无任何反馈。

### 审查后接受、不修（执行时记入 Project.md 已知边界）

- 内联 on* 事件处理器与 `javascript:` 链接：sandbox 无 allow-scripts 使帧内一切脚本（含内联处理器）不可执行，父侧又对全部帧内链接 preventDefault，双重边界成立（维持既有已知限制）。
- 远程图片/追踪像素加载：「默认 HTML 渲染」的既定语义；加 CSP 会连带破坏含远端图片的文档。
- `<base href>` 劫持：仅影响相对资源解析，影响面被上一条覆盖。
- 偏好文件（settings.json）非原子写：损坏自愈为默认值，代价收益不成比例。
- 跨进程多实例并发修改 settings.json：维持既有多实例已知限制，单进程内互斥足以保障单实例正确性。

## 4. 架构决策

| 决策项 | 选择 | 理由 | 替代方案（为何不选） |
|--------|------|------|----------------------|
| 渲染调度 | 单一尾随节流（80ms）+ `cancel()` 接口：仅管理触发时机，待渲染期间合并调度，突发结束 ≤80ms 内渲染末态；异步响应丢弃由既有 `renderVersion` 负责；程序性加载前显式调用 `cancel()` | 最小状态契约，彻底杜绝输入期间饥饿与旧 timer 污染；既有两常量防抖覆盖节流属死逻辑 | 引入复杂 running/scheduled 状态机（过重、易死锁或丢失末态）；保留防抖加 maxWait（两套常量语义重叠） |
| 并发治理 | App 层单一读写锁守护设置/脏/退出状态，新增 `shouldPreventClose()` 加锁快照供 `main.go` 调用，并串行化共享 JSON 单进程全部写路径 | 根因处守护全部共享字段；彻底解决 `main.go` 钩子无锁直接读取竞争；读多写少用读写锁 | 跨包共享锁（需新增包，违背 internal 禁互依与最小面）；文件锁（过重）；跨进程锁（超出轻量范围，Project 明确接受多实例限制） |
| 保存安全 | 同目录临时文件 + 继承原权限 + `f.Sync()` + 改名替换（崩溃安全最佳努力替换） | 写入中途崩溃或失败时目标文件保持旧内容不损，任一步骤失败自动清理临时文件；继承原权限保持文件属性一致 | 平台条件编译专用 API（如 Win32 ReplaceFile，破坏 Linux 开发环境一致性与最小代码原则）；直接覆写（崩溃致数据截断丢失） |
| meta refresh | 与 script 剥离同层，在渲染输出统一剥离，正则支持属性引号边界与精准 refresh token 匹配 | 修复点在既有输出净化层，属性引号匹配杜绝被属性值含 `>` 截断，精准匹配避免误删合规标签 | 引入庞大外部 HTML 解析库（违背零依赖与轻量原则）；CSP meta（连带阻断远程图片，破坏默认 HTML 渲染语义） |
| 预览变更检测 | HTML 与 CSS 独立检测更新（`lastWrittenHtml` / `lastWrittenCss`） | 样式与正文解耦：切主题/改字体仅改 `<style>`，正文与 KaTeX 零开销；无变动全跳过 | 仅支持整包一致性判断（切字体仍触发昂贵的正文 DOM 重排与公式回填） |
| 打开确认时机 | 统一抽取 `openPath`，确认前移至读取之前，统一捕获错误并提示 | 标题/最近文件副作用只在确认打开后发生，时序归位；单点函数杜绝拖放未捕获拒绝 | 打开绑定改纯读 + 确认后补记（扩大绑定面并增加 wailsjs 手同步负担） |
| 字体分发 | 复制前清空字体目录，仅复制源目录下的 `.woff2` 文件，验收与源目录动态对照 | WebView2/Chromium 恒选 woff2，清除无用 woff/ttf 减重约 850KB；动态对照避免绑定特定补丁版本 | 维持三格式（体积浪费）；硬编码文件数断言（升级版本易误报） |

**拒绝项清单**（已评估，不实施）：

- **KaTeX 懒加载/代码分割**：公式渲染默认开启，收益仅几十毫秒的脚本解析，代价是双 bundle 与加载时序管理，违背最小面。
- **增量 DOM 渲染**：全量交换 + 公式缓存是既定架构（srcdoc 重建禁忌、原地更新模型），推翻属大重构。
- **goldmark 引擎复用**：实例非并发安全、创建成本低，为既定决策。
- **mathCache 淘汰策略**：500 项全清为 2026-09-02 既定决策，影响可忽略，不翻案。
- **预览帧 CSP / on* 与 javascript: 额外过滤**：sandbox 已阻断帧内脚本执行，进一步过滤破坏合法 HTML 与远端图片语义。
- **Windows 专用原子替换 API**：条件编译增加跨平台维护成本，最佳努力临时文件替换已足以保障崩溃安全。

## 5. 风险清单

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 无头检查脚本用 execCommand 驱动编辑器可能因引擎差异不稳 | 🟡 中 | 脚本为 dev-only（不进 npm test/CI），失败时先复核脚本自身（选择器、等待时机）再动产品代码；提供 CHROME_BIN 覆盖 |
| 数据竞争检出依赖调度时序，竞态测试可能偶发漏报 | 🟡 中 | 测试桩内注入非并发安全共享结构并在读写间增加微小延时，使未加锁竞争 100% 触发 `-race` 或 panic；锁设计以逻辑审查为准 |
| 节流行为变化改变编辑手感（预览更跟手） | 🟢 低 | 间隔常量维持 80ms 不变，仅使行为对齐既定意图；如需回退仅调常量 |
| 打开确认前移后「选中打不开的文件也会先弹确认」 | 🟢 低 | 罕见路径且无数据风险（内容不离开编辑器），记入 Project.md 已知取舍 |
