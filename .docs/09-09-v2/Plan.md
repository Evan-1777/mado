## 1. 背景与目标

针对 09-09-v1 版本重构后的代码质量审计反馈，执行最短有效差分修复，消除潜在状态抖动、测试假阳性、启动样式竞争与无障碍缺陷：
1. 状态栏文案彻底中文收敛：修复新建与加载文档流程遗留的硬编码英文 `'Ready'`；
2. 契约测试加固：在 `uiContract.test.mjs` 中补充退役英文状态文案的负向断言防线；
3. 首屏特异性：在 `index.html` 根标签显式声明 `data-theme="dark"`，杜绝 CodeMirror 初始背景未命中样式；
4. ARIA 无障碍合规：模式 Tab 按钮补齐唯一 id，分栏补齐 `role="tabpanel"` 与 `aria-labelledby`，侧栏折叠按钮补充动态 `aria-label`；
5. 设计令牌自洽与滚动条统一：raw palette 注册 `--white` 并替换裸色，新增 `--focus-ring` 提升暗色焦点环可见度，预览样式表注入定制滚动条规则。

## 3. 架构决策

| 决策项 | 选择 | 理由 | 替代方案（为何不选） |
|--------|------|------|----------------------|
| 焦点环语义令牌 | 引入 `--focus-ring`（暗色 `--blue-400`，浅色 `--blue-600`） | 暗色下 `--blue-600` 对比度仅 3:1，`--blue-400` 对比度超过 10:1 符合 WCAG AA | 在组件级硬编码特判颜色（破坏设计令牌层级） |
| 根标签默认主题声明 | `index.html` 静态标记 `data-theme="dark"` | 消除 JS 异步获取设置前的样式空白窗口，确保 `:root[data-theme]` 规则即时命中 | 降低 CSS 特异性或内联追加覆盖规则（增加选择器复杂度） |
| 滚动条一致性 | 在 `base.css` 注入与外壳对称的 `::-webkit-scrollbar` 规则 | 消除 iframe 与外壳原生 17px 滚动条割裂感，继承已有的 `--border` 与 `--muted` 令牌 | 使用 JS 模拟滚动条（破坏原生性能与惯性滚动） |

## 4. 风险清单

| 风险 | 等级 | 缓解措施 |
