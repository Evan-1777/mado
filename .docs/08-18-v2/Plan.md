## 1. 背景与目标

在前期移除层级深度缩进以改善水平排版时，误移除了目录大纲的层级折叠能力。本次计划在保留平铺色彩层级（无缩进深度）视觉优势的基础上，恢复并优化目录树折叠交互与侧栏默认状态，达成以下目标：

- 恢复多层级标题树形结构与父节点折叠/展开能力
- 默认目录节点全部展开展示，保持平铺排版与字阶/色彩层级
- 目录栏顶部右侧增加快捷按钮，支持在「全部展开」与「全部收起」之间一键切换
- 目录侧栏默认状态调整为收起（宽度 40px），用户需要时可点击展开

## 3. 架构决策

| 决策项 | 选择 | 理由 | 替代方案（为何不选） |
|--------|------|------|----------------------|
| 目录渲染方式 | 深度优先平铺 DOM 行 + CSS 无缩进排版 | 保证性能与简洁性，无需嵌套 DOM 容器即可实现平滑折叠 | 嵌套多层 DOM div（增加 DOM 深度与排版复杂度） |
| 折叠状态保持 | 基于标题路径/特征签名的状态映射缓存 | 用户在编辑文档时输入非结构字符不会破坏手动折叠状态 | 每次重新解析全量重置（破坏编辑体验） |
| 全部展开/收起 | 动态二态计算切换按钮 | 单按钮自适应当前状态，节省顶部空间，语义明确 | 双按钮并排（侧栏空间紧凑，双按钮拥挤） |
| 侧栏默认状态 | 初始 `collapsed` 类，按需展开 | 聚焦内容区域，降低初次加载视觉干扰 | 默认展开（占用固定侧边空间） |
